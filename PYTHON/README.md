# Python Analysis
This folder contains the Python-based data analysis performed for the **IBM HR Analytics & Employee Attrition** project.

## File
### IBM_HR_Analytics_Analysis.py
This Python script contains the data analysis and exploratory analysis performed on the cleaned IBM HR dataset.
The analysis includes:
- Loading and inspecting the dataset
- Data cleaning and preprocessing
- Handling missing values and duplicate records
- Exploratory data analysis
- Descriptive and statistical analysis
- Employee attrition analysis
- Department and job role analysis
- Salary and compensation analysis
- Employee satisfaction analysis
- Data visualization

## Libraries Used
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computations
- **Matplotlib** – Data visualization

The Python analysis complements the SQL analysis and Power BI dashboard developed as part of the project.
