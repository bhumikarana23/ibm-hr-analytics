# SQL Analysis
This folder contains the SQL queries used to analyze the **IBM HR Analytics & Employee Attrition** dataset.

## File

### IBM_HR_Analytics_SQL_Queries.sql
This SQL script contains queries developed to analyze employee demographics, job characteristics, compensation, satisfaction, and attrition patterns.
The analysis includes:

- Employee and department analysis
- Employee attrition analysis
- Attrition by department and job role
- Salary and compensation analysis
- Age and demographic analysis
- Job satisfaction analysis
- Work-life balance analysis
- Aggregations and comparative analysis
- Filtering, grouping, sorting, and conditional analysis

The SQL analysis is performed using the cleaned dataset prepared during the Excel data-preprocessing stage and provides insights that support the Power BI dashboard.

## Tools Used
- MySQL
- MySQL Workbench
