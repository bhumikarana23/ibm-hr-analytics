# Data
This folder contains the original raw dataset used for the **IBM HR Analytics & Employee Attrition** project.

## File

### IBM_HR_Analytics_Raw_Data.csv
This CSV file contains the original employee-level HR dataset used as the starting point for the analysis. It includes employee demographic, job-related, compensation, satisfaction, and attrition-related information.
The raw dataset is preserved without modifications to maintain data integrity and provide a reference for the data cleaning, analysis, and visualization stages of the project.

## Usage
The dataset is used as the input for:
- Data cleaning and preprocessing
- Exploratory data analysis
- SQL-based analysis
- Excel analysis and Pivot Tables
- Power BI dashboard development
- Employee attrition and HR insights
