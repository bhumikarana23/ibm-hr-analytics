# ibm-hr-analytics-dashboard
HR analytics dashboard analyzing employee attrition, demographics, and workforce insights using Excel, SQL, Power BI, and Python.
# 👥 IBM HR Analytics & Employee Attrition Dashboard

## Overview
This project presents an end-to-end HR analytics solution using the IBM HR Analytics Employee Attrition dataset. The objective was to analyze workforce data, identify factors influencing employee attrition, and generate actionable insights through data analysis and interactive visualizations.

The project combines Excel, SQL, Power BI, and Python to examine employee demographics, job roles, compensation, satisfaction levels, work-life balance, and attrition patterns.

---

## Objectives
- Clean and prepare HR data for analysis.
- Identify factors contributing to employee attrition.
- Analyze workforce demographics and performance metrics.
- Answer business questions using SQL.
- Develop an interactive HR analytics dashboard.
- Perform exploratory data analysis using Python.

## Project Workflow

### 1. Data Cleaning (Excel)
- Cleaned and validated employee records.
- Checked for missing, duplicate, and inconsistent data.
- Standardized fields for further analysis.

### 2. Exploratory Data Analysis (Excel)
Created Pivot Tables and charts to analyze:
- Employee Attrition
- Department-wise distribution
- Gender distribution
- Age groups
- Job Roles
- Education Levels
- Monthly Income
- Years at Company

### 3. SQL Analysis (MySQL)
Used SQL to answer business questions related to:
- Attrition by department
- Average salary across job roles
- Attrition by age group
- Employee demographics
- Job satisfaction and work-life balance
- Department-wise workforce distribution

### 4. Dashboard Development (Power BI)
Developed an interactive dashboard featuring:
- Employee Count
- Attrition Rate
- Active Employees
- Average Age
- Average Monthly Income
- Department-wise Analysis
- Job Role Analysis
- Education Analysis
- Gender Distribution
- Interactive filters and slicers

### 5. Python Analysis
Performed additional data analysis using:
- Pandas
- NumPy
- Matplotlib

---

## Business Insights
The project helps answer questions such as:
- Which departments have the highest attrition?
- Which job roles experience the greatest employee turnover?
- How does attrition vary across age groups?
- Is employee attrition related to salary or years at the company?
- Which employee segments require greater retention efforts?
