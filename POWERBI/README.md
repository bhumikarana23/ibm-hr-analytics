# Power BI Dashboard
This folder contains the interactive Power BI dashboard developed for the **IBM HR Analytics & Employee Attrition** project.

## File

### IBM_HR_Analytics_Dashboard.pbix
This Power BI file contains an interactive analysis of employee demographics, job characteristics, satisfaction, compensation, and employee attrition.

### Key Features
- Key Performance Indicators (KPIs)
- Overall employee and attrition analysis
- Attrition by department and job role
- Attrition by age group and gender
- Job satisfaction and work-life balance analysis
- Salary and compensation analysis
- Interactive slicers and filters
- Employee demographic analysis

The dashboard is developed using the cleaned dataset prepared during the Excel data-preprocessing stage and provides interactive visual insights into employee attrition and HR patterns.
